### 사용자와 일하는 규칙 (꼭 지킬 것)

- **한국어로 답하기.** 판 → "버전" 이라고 쓰기
- **릴리스는 사용자가 하자고 할 때만.** 베타라 1.0.x 끝자리만 올림 (다음은 v1.0.3). 사용자가 직접 태그를 올리기도 함
- **앱은 원래 드림랜드 기능을 절대 막거나 방해하면 안 됨.** 크롬에서 되는 건 앱에서도 똑같이 (26번). 드림랜드에 없는 제한을 새로 넣지 말 것
- **보안 손질은 더 하지 않음** — 드림랜드 저장소가 맡음. 기능 버그만 고침
- 커밋 · 푸시는 사용자가 하자고 할 때 (보통 "커밋하고 푸시해")
- **폰(S22)을 만질 때:** 사용자가 Remote Control 로 폰의 Claude 앱에서 대화를 보고 있을 때가 많음
  - 키를 누르기 전에 `dumpsys activity activities | grep topResumedActivity` 로 앞에 뜬 앱을 확인 (Claude 앱이면 거기 키가 들어감)
  - 오래 쓸 때는 먼저 물어보고, 짧게 시험한 뒤에는 `am start -n com.anthropic.claude/.mainactivity.MainActivity` 로 Claude 앱을 다시 앞으로
  - 드림랜드 설정 · 데이터를 바꾸지 말 것: 고르기 · 입력 시험은 시험용 요소를 페이지에 잠깐 넣어서 하고 지움. 화면(탭)을 옮겼으면 캐릭터 탭으로 돌려 둠 (드림랜드가 마지막 화면을 기억함, 25번)
  - 권한 · 마이크 허용 창은 사용자가 직접 누름

### 다음 세션에서 이어서 하는 법

```sh
# 빌드 (Gradle JDK 는 21 — Android Studio 기본 JDK 25 로는 안 됨)
JAVA_HOME="C:/Users/천보람/.jdks/jbr-21.0.11" ./gradlew assembleDebug
# 폰에 설치 (기기가 여러 대면 -s 로 고르기. adb devices -l 로 확인)
"$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe" -s <기기> install -r app/build/outputs/apk/debug/app-debug.apk
# 릴리스: v 로 시작하는 태그를 올리면 Actions 가 빌드해서 Releases 에 올림
# (사용자가 하자고 할 때만) git tag -a <태그> -m "..." && git push origin <태그>
```

- 공기계 무선 디버깅: 폰의 개발자 옵션 → 무선 디버깅 화면에 나온 주소로 `adb connect <IP:포트>` (페어링은 이미 함. 포트는 껐다 켜면 바뀜)
- 화면 속을 들여다볼 때: 디버그 빌드는 WebView 개발자 도구가 켜져 있음. 도우미 스크립트는 `tools/` 에 있음
  ```sh
  ADB="$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"
  PID=$("$ADB" -s R3CT705TNAR shell pidof com.dreamland.webview | tr -d '\r')
  "$ADB" -s R3CT705TNAR forward tcp:9222 localabstract:webview_devtools_remote_$PID
  node tools/cdp.js 9222 start.html "document.body.className"        # 첫 화면
  node tools/cdp.js 9222 127.0.0.1:4173 "history.state.page"        # 드림랜드 화면 (지금 페이지)
  node tools/cdpg.js 9222 127.0.0.1:4173 "..."                      # 사용자가 누른 것처럼 (window.open · 클립보드 등)
  node tools/cdpcrash.js 9222 127.0.0.1:4173                         # 웹 화면 일부러 죽이기 (24번 시험)
  ```
  - 앱이 뒤에 있으면 평가가 멈출 수 있음 → `timeout 10 node ...` 로 감싸기
  - 화면 좌표: S22 는 CSS px × 3.75, 상태 표시줄 약 101px 아래부터 드림랜드 화면
  - 빌드 도구(aapt)는 경로에 한글이 있으면 못 엶 → 영어 경로로 복사해서 보기
- GitHub CLI(`gh`)는 이 컴퓨터에 없음. 빌드 · 릴리스 상태는 공개 API 로 확인:
  `curl -s https://api.github.com/repos/IY-0320/webview-app/actions/runs?per_page=3`, `.../releases`
- 드림랜드 소스를 볼 때: `git clone https://github.com/geminibug2026/DreamLand.git` 해서 읽기만 (자주 바뀜)

   - **다른 사이트 파일**(`<a download>` 가 다른 주소): 전에는 아무 일도 없었음 → 브라우저로 넘김
   - 원래와 같아서 둔 것: 복사(실제 탭에서 됨), 키보드(입력칸이 키보드 위에 보임), 알림(`Notification` — 폰 크롬에서도 안 됨), 폴더 고르기(폰 크롬에서도 안 됨)
   - 참고: "이타도리 유우지 · 대화 1" 이 비어 보인 건 서버에도 메시지 0개인 대화라서 (앱 문제 아님)

27. **뒤로가기: 열린 창부터 닫고, 없으면 바로 첫 화면으로** (2026-11-27 사용자 요청, S22 에서 확인)
   - 전에는 드림랜드 안의 이전 화면(기록)을 하나씩 거슬러 올라감 → 이제 드림랜드 기록과 상관없이 한 번에 첫 화면(꿈속으로)
   - 드림랜드 위에 떠 있는 게 있으면 맨 위 하나만 닫음 (`BACK_JS`): 앱이 띄운 새 창(인쇄 등) → 드림랜드 창(`#modals`, X 단추) → 메뉴(`.menu-x`) → 그림 크게 보기 · 일기장 책 · 명령 찾기 등(닫기 단추, 없으면 Esc) → 장면 패널 · 대화 목록(열었던 단추를 다시 누름)
   - Esc 는 마지막 수단 (드림랜드에서 Esc 는 "답 받는 중 멈추기"도 함). 같은 것이 두 번 연달아 안 닫히면 갇히지 않게 첫 화면으로
   - 시험: 대화 목록 + 장면 패널 + 대화 메뉴를 열고 뒤로 → 메뉴 · 패널 · 목록 차례로 닫히고 네 번째에 첫 화면 / 더보기 창 → 뒤로 한 번에 창만 닫힘. 첫 화면에서 한 번 더 → 앱 종료

28. **고르기 칸 · 입력칸 추천 · 막대 색 · 화면 크기 방식** (2026-11-27, S22 에서 확인)
   - **고르기 칸(`<select>`)**: WebView 는 안드로이드 기본 대화상자(어두운 창)로 띄웠음 → `Picker.kt` 가 페이지 안에 아래에서 올라오는 시트를 그림. 색 · 글꼴 · 모서리는 지금 드림랜드 테마의 CSS 변수(`--surface --text --dim --accent --line --r --font`)라 테마를 바꾸면 같이 바뀜. 고르면 값 + input/change 이벤트. 여러 개 고르기 · 목록형은 그대로 둠. 뒤로가기로 닫힘
   - **입력칸 추천(`<input list>` + datalist, 기능 › 보조 연결의 모델 칸 등)**: WebView 의 기본 추천 창은 키보드가 올라와 화면이 줄어도 처음 자리(키보드 위)에 남음 (WebView 자체 한계, 아래 방식 바꿔도 같음)
     → 칸에 들어가 있는 동안만 `list` 속성을 떼어 기본 창을 막고, 칸 바로 밑(자리가 없으면 위)에 테마색 목록을 그림. 칠수록 걸러짐. 고르면 React 가 알아채게 원래 value setter + input/change. 칸을 나가면 `list` 를 되돌림
   - **화면 크기 방식**: `themes.xml` 의 `Theme.Dreamland` 에서 Android 15 edge-to-edge 강제를 끔(`windowOptOutEdgeToEdgeEnforcement`) → 크롬처럼 시스템이 상태 표시줄 · 아래 막대 · 키보드만큼 화면을 줄임. 막대 색은 `statusBarColor` · `navigationBarColor` 로 칠함 (22번의 손으로 맞추던 여백은 이제 0이 됨. targetSdk 36 으로 올리면 이 설정이 없어지니 다시 봐야 함)
   - **막대 색 버그**: 드림랜드 일부 배경이 `color(srgb 1 1 1)` 꼴(0~1)이라 흰색을 거의 검정(1,1,1)으로 읽어 상태 표시줄이 검게 나왔음 → 0~1 값은 255 배
   - 첫 화면 여백 기본값 24px → 0 (막대 밖에만 그리므로)
   - 시험은 데이터를 바꾸지 않게 시험용 칸을 넣어서 함 (고르기: 포도 → change 이벤트 / 추천: beta-model → input 이벤트, 키보드 유지)

29. **드림랜드 → 첫 화면 돌아올 때 매끄럽게** (2026-11-27, S22)

## 알아 둘 것

- 삼성 **보안 폴더**에 있는 터묵스도 같은 폰의 `127.0.0.1` 을 씀. 그래서 보안 폴더의 실리태번(:8000)이 열렸던 것
- 드림랜드 서버는 `Host` 헤더가 `localhost` / `127.0.0.1` 일 때만 받음 (`server.js` `hostOk`). 다른 기기에서 접속하려면 드림랜드를 `--lan` 으로 켜야 함
- 드림랜드 데이터는 웹뷰 저장소에 저장되고, 주소(포트)별로 따로임. 주소를 바꾸면 다른 데이터로 보일 수 있음
  - 단, 드림랜드 설정의 "서버 폴더 저장"이 켜져 있으면 터묵스의 `dreamland/data/store` 에도 저장돼서 앱을 지웠다 깔아도 돌아옴 (S22 가 그랬음)
- 드림랜드 보안 정책(CSP)이 `connect-src *` 라 페이지 안에서 `blob:` 주소를 fetch 할 수 없음. 드림랜드는 `fetch` 도 자기 것으로 감싸 둠
- 디버그 APK 와 배포용 APK 는 서명이 달라서 서로 덮어 설치할 수 없음
- 빌드할 때 `aapt2 ... Failed to stat file ... android.jar: Illegal byte sequence` 경고가 뜨는데, 사용자 폴더 이름이 한글이라서임. 빌드는 정상 완료되므로 무시해도 됨
- `MainActivity.kt` 의 `databaseEnabled` 는 deprecated 경고만 뜸 (동작에는 문제 없음)
