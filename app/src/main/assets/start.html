INSTALL

드림랜드 들이기

드림랜드는 터묵스라는 작은 리눅스 앱 안에서 돌아가요. 네 단계면 끝나요.

01
터묵스 설치—
F-Droid 나 GitHub 에서 받아 주세요. 다 깔았으면 이 화면으로 돌아오면 저절로 표시돼요.
02
터묵스 준비
터묵스를 한 번 열어 첫 설치가 끝나길 기다린 뒤, 아래 명령을 붙여 넣고 엔터를 눌러 주세요. 이 앱이 터묵스에 부탁할 수 있게 하는 설정이에요. 다 했으면 오른쪽 위를 눌러 했어요로 바꿔 주세요.

        

      

    


    

      03
      
실행 권한—

      
이 앱이 터묵스에 "드림랜드 켜 줘" 하고 부탁하도록 허락해 주세요.

    


    

      04
