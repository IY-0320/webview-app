INSTALL

드림랜드 들이기

드림랜드는 터묵스라는 작은 리눅스 앱 안에서 돌아가요. 네 단계면 끝나요.

01
터묵스 설치—
F-Droid 나 GitHub 에서 받아 주세요. 다 깔았으면 이 화면으로 돌아오면 저절로 표시돼요.
02
터묵스 준비
터묵스를 한 번 열어 첫 설치가 끝나길 기다린 뒤, 아래 명령을 붙여 넣고 엔터를 눌러 주세요. 이 앱이 터묵스에 부탁할 수 있게 하는 설정이에요. 다 했으면 오른쪽 위를 눌러 했어요로 바꿔 주세요.

        

      

    


    

      03
      
실행 권한—

      
이 앱이 터묵스에 "드림랜드 켜 줘" 하고 부탁하도록 허락해 주세요.

    


    

      04

DREAMLAND

      

        
알림과 전화는 드림랜드가 보내는 것을 받아서 보여 줘요. 드림랜드에서 이것들이 켜져 있어야 해요.

        
    
          
  1. 대화방을 대화 모드로
    2. 
          
  2. 대화방 위 ⋯ 메뉴 › 대화 모드 설정 › "먼저 오는 연락" 탭 아래쪽의 "화면을 안 보고 있을 때 온 연락을 브라우저 알림으로 받기" (드림랜드 설정의 "대화 모드: … 알림으로 받기"와 같은 스위치예요)
    3. 
          
  3. 앱을 나가 있어도 먼저 연락을 받으려면: 같은 탭의 "내가 조용하면 캐릭터가 먼저 말 걸기"와, 그 아래 분 · 시간 칸들 밑의 "화면을 안 보고 있을 때도 보내기"
    4. 
          
  4. 전화: 전화 설정 › "대화 중에 캐릭터가 직접 전화 걸기". (드림랜드의 "캐릭터가 먼저 전화하기"는 드림랜드를 보고 있을 때만 걸려 와요)
    5. 
        

        
이 설정들은 원래 드림랜드에 있는 것이고, 앱은 바꾸지 않아요.
